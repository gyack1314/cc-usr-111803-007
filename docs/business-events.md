# 来源变化

道路解除只改变命中方向和时段的报价解释，其他方向不应受影响。

event-pending.json 表示来源目录已发现资料但正文尚未取得，event-complete.json 表示补取的原文字节已进入接收链。来源字段与既有资料的关系需根据业务事实核对。

# 线路状态与报价说明

当前线路状态由方向、路段与公告时段共同决定：同一公告只以最新已收版次参与当前判断，被修订取代的版次保留在事件时间线；解除通知按声明的方向与解除时刻作用于对应路段方向，并记录其声明解除的公告编号。来源目录要求的版次尚未取得、或必需来源正文未到时，相应方向判断保持待核；报价缺少道路公告时保持待核，不能仅由报价变化推断封路。每条报价说明列出采用的来源（类别、id、版次与收据摘要），已发布视图保持冻结，新的判断不改写历史发布。
